# WA Campaign App (Android APK Builder)

இந்த Repository உங்கள் வாட்ஸ்அப் மார்க்கெட்டிங் என்ஜினைக் கட்டுப்படுத்தும் ஒரு ஆண்ட்ராய்டு ஆப் ஆகும்.

## அம்சங்கள்:
1. Unlimited Group Creation
2. Dark Theme & Light Theme Switcher
3. தமிழ், English, हिंदी மொழி ஆதரவு
4. WhatsApp Pairing & Server IP Settings
5. Live Progress Bar (Sent, Failed, Pending)

## APK டவுன்லோட் செய்வது எப்படி?
1. இந்த ஜிப் ஃபைலில் உள்ள அனைத்து ஃபைல்களையும் உங்கள் புதிய GitHub ரெப்போசிட்டரியில் (main branch) push செய்யவும்.
2. GitHub தானாகவே **Actions** டேப்பில் பில்ட் செய்து 2 நிமிடத்தில் `wa-campaign-debug-apk` என்ற ரெடி-மேட் APK ஃபைலை Artifacts-ல் தரும்.
3. அதை உங்கள் போனில் டவுன்லோட் செய்து Install செய்து கொள்ளலாம்!
